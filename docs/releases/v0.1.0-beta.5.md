# Glass Terminal v0.1.0-beta.5

这是一个终端实时输出、AI 审核模式与界面一致性维护版本，重点修复 POSIX 类 Shell 的 AI 结构化命令延迟刷新、主机审核默认值丢失和修改消息后审核模式回退的问题，并改善亮色主题和中文导航。

## 终端实时输出

- POSIX、WSL 和 Git Bash 的结构化命令不再固定扣留末尾字符；CMD 保持原有过滤行为。
- 显示过滤器现在只暂存可能组成内部结束标记的最长歧义后缀；普通短输出、无换行认证提示和 `\r` 进度会在到达主进程后立即进入公共终端。
- 同一匹配逻辑也用于 Agent 命令输出捕获，避免工具输出流无必要地落后于可见终端。
- 内部 envelope、随机 nonce、START/END sentinel 和退出码仍不会显示；跨 SSH 数据块的任意标记分片均有回归覆盖。
- PowerShell 保持既有 OSC Shell Integration 和原样显示链路，不经过 sentinel 显示过滤器，本次没有修改其行为。

## AI 审核模式

- 每台 SSH 主机保存最后选择的“全部审核 / 风险审核 / 完全访问”，新连接与历史会话重连自动继承；本地终端仍默认“全部审核”。
- 首次选择“完全访问”仍需橙色风险确认；确认后的选择作为该主机默认值持久化，并继续受当前 SSH/SFTP 账号和操作系统权限限制。
- 主机详情显示当前“AI 默认审核”，切换模式后同步刷新。
- 修复“修改并重发”重建对话上下文时把刚选择的“完全访问”回退为旧模式的问题；审核模式保存期间禁止抢先发送，重发始终使用已经生效的当前模式。
- 用户打断当前消息时保留正在使用的审核模式，后续重发或继续对话不再自动回到“全部审核”；人工接管、断线和 Provider 安全边界仍按各自策略处理。
- 打断或异常失败的轮次会保存未完成 checkpoint，保留当轮用户消息和已显示的助手进展；只有完整持久化的轮次才推进终端上下文游标，因此下一条消息还能获得打断阶段新增的终端输出。

## 界面修复

- 修复亮色主题中“执行过程”展开区域沿用暗色背景、正文对比度不足的问题。
- “管理 AI Provider”主按钮在亮色和暗色主题中统一为实心绿色样式。
- 最左侧主导航由符号改为“终端 / 主机 / 文件 / 历史”中文文字，设置按钮保持齿轮图标。
- 主机面板顶部的导入、导出箭头改为“导入”“导出”，添加主机继续使用 `＋`。

## 验证

- POSIX 认证提示会在安全人工输入提交前发送到 Renderer。
- 结束标记逐字符分片测试确认普通输出不丢失、不重复，内部标记不泄露。
- 亮色主题关键样式和中文导航增加自动化回归测试。
- TypeScript 类型检查通过；全量 Vitest 为 67 个测试文件、615 项通过，3 个文件/5 项按环境跳过；Renderer、Electron 生产编译、Windows x64 解包发行构建和发行版本地 PTY smoke 均通过。
