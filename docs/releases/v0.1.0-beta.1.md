# Glass Terminal v0.1.0-beta.1

这是一个面向 `v0.1.0-beta.0` 的紧急维护版本，重点修复远程 SFTP 文件浏览器无法打开目录、Codex App Server 无法自动发现常见 CLI 安装的问题，并进一步精简 Windows 窗口界面。建议所有 Beta.0 用户升级。

## 重点修复

### 📁 修复远程 SFTP 目录无法打开

- 修复打开任意远程目录时出现 `Error invoking remote method 'sftp:list-directory': Error: End of file`，导致 SFTP 文件浏览器不可用的问题。
- 问题源于大目录流式枚举优化：底层改用 `opendir(handle) + readdir(handle)` 分批读取后，SFTP 协议用于表示“目录已经读取完成”的 `SSH_FX_EOF (code=1)` 被错误地当成了失败。
- 现在 `SSH_FX_EOF` 会被正确识别为正常完成；权限不足、连接中断及其他真实 SFTP 错误仍会照常报告，不会被吞掉。
- 空目录、普通目录和分批读取完成后都会正常关闭 SFTP 目录句柄，保留此前大目录有界枚举的内存优化。
- 新增真实 EOF 语义的回归测试，防止测试 Mock 再次使用不符合实际协议的空数组结束方式而漏掉此类问题。

### 🪟 精简原生窗口菜单栏

- 主窗口和设置子窗口默认隐藏 Electron 自动生成的 `File / Edit / View / Window` 菜单栏，减少与 Glass Terminal 自身界面无关的视觉占用。
- 菜单功能没有被删除；需要刷新、缩放或打开开发者工具时，仍可按一次 `Alt` 临时显示。

### 🤖 修复 Codex App Server 自动检测与启动

- 修复文档声称可自动检测 Codex CLI，但实际只检查已保存路径和未内置的打包路径，导致“自动检测并启动”在常见安装上失败的问题。
- 现在支持安全地解析 `PATH`、全局 npm 安装以及官方 OpenAI VS Code/Cursor/Windsurf 扩展中的 Codex CLI；所有候选项都会先转为绝对路径，不通过 shell 执行裸命令。
- Windows Store 中不允许外部启动的 Codex 应用别名会被正确跳过，并继续查找可执行的编辑器扩展版 CLI。
- 修复 CLI 在版本号之前输出警告时被误判为无效可执行文件的问题。
- 手动选择 `codex.exe` 现在会先验证再保存和重启；选错文件不再覆盖正确配置，也不会断开已经可用的 App Server。
- 已保存的 CLI 路径被移动或删除时，界面会显示具体路径诊断；自动启动也加入未处理异常兜底，避免影响主窗口。
- 真实 `codex app-server` 集成测试已覆盖本机 CLI 自动发现、`initialize` / `initialized`、账号状态读取和子进程回收。

## 升级说明

- 可以从 `v0.1.0-beta.0` 直接覆盖升级。
- 本版本不修改 Host、Provider、Session、终端日志或凭据存储格式，不需要执行数据迁移。
- 用户数据目录仍为 `%APPDATA%\glass-terminal\`，已有主机、会话和设置保持不变。

## 验证

- `npm run build`：类型检查、全量测试、Renderer 与 Electron 生产构建通过。
- 70 个测试文件通过，4 个按环境跳过；682 项测试通过，14 项跳过。
- 当前本机 `codex-cli 0.148.0-alpha.21` 真实 App Server 握手和进程退出检查通过，关闭后无遗留 Codex 子进程。
- 真实远程主机 SFTP 根目录、子目录和目录读取完成路径已完成手动回归，原 `End of file` 故障确认恢复。
- 工程根目录 `npm start` 可正常拉起修复后的界面。
